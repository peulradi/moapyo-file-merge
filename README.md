# 모아표 파일 취합·중복 검수

여러 CSV·XLSX를 하나의 Excel 파일로 합칩니다. 전체 값이 같은 중복과, 같은 식별값의 내용이 다른 행을 구분합니다.

브라우저에서 CSV를 바로 처리하려면 [모아표](https://moagraph.kr/)를 이용하세요. 가입 없이 사용할 수 있습니다. Windows 실행 파일과 합성 예시의 결과도 사이트에서 받을 수 있습니다.

## 처리 방식

- 원본 파일을 덮어쓰지 않습니다.
- 전체 값이 같은 행만 선택적으로 제외하고, 제외 기록을 남깁니다.
- 같은 식별값의 수량·금액 등이 다르면 삭제하지 않고 검수 대상으로 표시합니다.
- 파일명, 시트명, 원본 행 번호를 결과에 남깁니다.
- CSV 식별값의 앞자리 0을 보존합니다. 입력 XLSX에서 이미 숫자로 바뀐 값은 복원하지 않습니다.
- 파일은 로컬에서 처리합니다. 네트워크 연결이 필요하지 않습니다.

표준 처리 범위는 입력 10개, 총 5,000행, 20열입니다. 설정 파일에서 열 이름의 대응과 식별 열을 지정할 수 있습니다.

## 실행

Python 3.12에서 검증했습니다. `openpyxl`이 필요합니다.

```powershell
python -m pip install -r requirements.txt
python merge_tool.py UTF8_합성자료.csv CP949_합성자료.csv --config 고객설정_예시.json --out result
```

새 `result` 폴더에 `취합결과.xlsx`와 `처리기록.json`을 저장합니다. 같은 결과 폴더가 이미 있으면 덮어쓰지 않고 중단합니다.

화면에서 파일과 설정을 선택하려면 다음 명령을 실행하세요.

```powershell
python gui.py
```

결과에는 `취합결과`, `검수대상`, `제외기록`, `처리기록` 시트가 포함됩니다. 예시 파일은 직접 만든 합성 자료입니다. 실제 거래나 고객 자료를 나타내지 않습니다.

## 이용 범위와 문의

제공한 소스·실행 파일은 내부 업무에 실행·수정할 수 있습니다. 제3자 라이브러리는 원래 라이선스를 따릅니다. 자세한 내용은 `USE-NOTICE.txt`를 확인하세요.

같은 양식을 반복 처리하는 업무에는 고객별 맞춤 설정을 제공합니다. 표준 설정 가격은 49,000원입니다. 범위와 결과 기준은 시작 전에 확인합니다. [사이트의 문의 안내](https://moagraph.kr/#inquiry)에서 열 이름과 익명 처리한 예시 3행을 보내주세요. 고객 자료를 공개 이슈에 올리지 마세요.
